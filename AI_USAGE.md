# AI Usage

## Использование искусственного интеллекта

При разработке проекта «ВышКат» использовался ChatGPT в качестве вспомогательного инструмента для изучения Go, обсуждения архитектуры приложения и подготовки тестов.

### 1. Проектирование архитектуры

ИИ помогал обсуждать структуру проекта и распределение ответственности между компонентами. В частности, рассматривались:

* разделение предметной области, бизнес-логики, консольного интерфейса и точки входа;
* применение интерфейсов для описания инвентарных объектов, транспорта и энергопотребляющих устройств;
* организация единого реестра имущества;
* внедрение зависимостей с помощью Uber Fx;
* применение принципов SOLID.

### 2. Реализация функциональности

ИИ использовался при подготовке и обсуждении решений для следующих компонентов:

* добавление объектов в парк и проверка уникальности инвентарных номеров;
* проведение технического осмотра перед постановкой объекта на баланс;
* формирование отчётов по количеству объектов, энергопотреблению и транспорту для новичков;
* создание консольного меню и обработка пользовательского ввода;
* настройка завершения приложения через механизм жизненного цикла Uber Fx.

### 3. Тестирование

С помощью ИИ были подготовлены идеи и примеры unit-тестов для проверки:

* успешного добавления объектов;
* отказа технического осмотра;
* обработки повторяющихся и пустых инвентарных номеров;
* корректности формирования отчётов;
* граничных значений уровня простоты для новичков;
* работы с пустым инвентарём.

Также обсуждалось использование тестовой реализации интерфейса технического осмотра (`FakeInspectionService`), позволяющей управлять результатом проверки без обращения к основной реализации.

### 4. Объяснение технологий

ИИ использовался для объяснения синтаксиса Go, интерфейсов, структур, обработки ошибок, утверждений типов, модульной структуры проекта и принципов внедрения зависимостей.

### 5. Проверка и ответственность за результат

Предложенные ИИ фрагменты кода и рекомендации должны быть интегрированы в проект, проверены компилятором и тестами. ИИ не заменяет самостоятельную проверку корректности реализации и соответствия требованиям задания.

Итоговая версия проекта должна быть проверена автором перед сдачей. При использовании предложенных фрагментов кода ответственность за итоговую реализацию, её работоспособность и соответствие заданию несёт автор проекта.
